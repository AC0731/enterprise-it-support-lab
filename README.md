# Enterprise IT Support Lab

A hands-on endpoint support and incident-triage project. The initial version intentionally contains a few defects that are diagnosed and corrected in later commits to document troubleshooting workflow.

## Current scope

- System inventory collection
- Disk utilization check
- DNS resolution validation
- TCP connectivity validation
- Service-state check
- Incident priority scoring
- JSON and Markdown evidence export

> This is a lab project using local/simulated endpoint data. It does not claim access to a production enterprise environment.

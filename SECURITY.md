# Security and data handling

This repository is a lab. Sample hostnames, users, asset identifiers, and incident data are fictional.

For real support work:

- Do not commit passwords, API keys, MFA codes, private keys, session cookies, or recovery codes.
- Redact public IPs, usernames, email addresses, tenant IDs, serial numbers, and internal hostnames before publishing evidence.
- Follow least privilege and approved elevation workflows.
- Treat remediation scripts as administrative tooling: review commands, use `-WhatIf` where supported, and capture pre-change state.
- Follow the employer's data-retention, ticketing, privacy, and incident-response requirements.

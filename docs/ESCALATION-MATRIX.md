# Escalation matrix

| Priority | Typical scope | Target response | Escalation trigger |
|---|---|---|---|
| P1 | Broad outage / critical business service unavailable | Immediate | Multiple sites/users, security impact, or critical service unavailable |
| P2 | Major degradation / many users | Urgent | Shared infrastructure, repeated failures, workaround limited |
| P3 | Single user or limited group | Standard | L1/L2 steps exhausted, admin/vendor action required |
| P4 | Request / information / low-impact observation | Planned | Change approval, fulfilment queue, or documentation update |

Priority is based on impact and urgency, not only technical severity. The Python scoring in this lab is a triage aid, not a replacement for organizational incident policy.
